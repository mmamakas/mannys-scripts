# Manny's Scripts

Collection of IT automation and onboarding scripts for system administration, security hardening, and client deployment.

## Contents

### Huntress Onboarding

Scripts for deploying and configuring Huntress EDR on client systems.

- **[Enable-HuntressAuditPolicy.ps1](Huntress-Onboarding/Enable-HuntressAuditPolicy.ps1)** - Configures Windows Advanced Audit Policy per [Huntress recommendations](https://support.huntress.io/hc/en-us/articles/49363914702867-Enforcing-Windows-Logging-Audit-Policies)

## Usage

Each script includes usage instructions in comments at the top of the file.

Most scripts require administrator/elevated permissions.
